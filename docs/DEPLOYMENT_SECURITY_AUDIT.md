# Deployment-focused security audit — October 26, 2026

Scope: FORGE's public demo boundary, startup configuration, model activation, container and HTTP verification. This is a source/test/local-container audit, not a penetration test or public-host certification. No genuine inference or paid service was used.

| Finding                                                         | Resolution/evidence                                                                                                                                                                        | Limit                                                                                                                                                                             |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Public route prefix accepted broader paths than intended        | Full-match allowlist: fixed entrypoints, one-level bundle assets,32-hex session IDs and exact report/advance suffixes; negative path tests                                                 | Router/storage still validate data independently                                                                                                                                  |
| No explicit Host boundary                                       | Exact configured hosts for public/private mode; duplicate, userinfo, malformed authority, wildcard and forwarded-host bypass tests                                                         | HTTPS ingress must preserve the reviewed Host; local mode remains local-only                                                                                                      |
| Uvicorn may trust forwarded headers by default                  | Public launcher disables proxy headers and server banner, constrains concurrency/backlog/keepalive, one worker                                                                             | Per-client quotas may be shared behind an ingress; they are not distributed DDoS protection                                                                                       |
| Container mode could be accidentally switched to developer mode | Launcher fails before serving unless public; rejects inference enablement, nonzero request budget, inference key and owner token                                                           | An operator with Docker control can override commands; do not do so on public hosting                                                                                             |

An isolated internal bridge prevented loopback published-port access here and was removed after testing |
| No repeatable deployed boundary check                           | Read-only audit: TLS verification required outside explicit literal loopback; no redirects, bounded8s/64KiB probes, security headers/no CORS/no-store, readiness and developer routes      | Does not mutate investigations or test payment/retention; local HTTP is explicitly labeled, never public HTTPS                                                                    |
| Manual inference activation could be mistaken for ready access  | Dry-default smoke with independent credit/card-free flags, secure credential, reviewed ID, one request/no retries, bounded reservations, private exclusive artifact and independent replay | Operator attestations are not billing verification; counters reset on restart; interruption requires provider-usage review                                                        |

Retained Phase3 defenses:1MiB body and15s read limit; strict Pydantic schemas; no user code/tool execution; prompt/output/timeout/retry bounds; escaped HTML; no automatic model fallback; public uploads disabled; version/lease guarded SQLite; bounded sessions/retention; structured credential-free logs; CSP/frame/referrer/permissions headers and no CORS grants. Public sessions contain only fixed synthetic data and are not private user storage. Hashes bind consistency, not authenticity.

The private owner API is separate and stays local. Current native model-image/audio ingestion is absent; only bounded numerical/context summaries are passed by the adapter. No future user/customer telemetry should be sent without a separate data-policy review.

## Hosting decision

- [HF Spaces official overview](https://huggingface.co/docs/hub/spaces-overview): static hosting is free, but Docker/Gradio compute requires a paid plan; separate free Gradio ZeroGPU eligibility does not establish a supported persistent FastAPI deployment. Do not call CPU Basic's lack of hourly fees a free Docker entitlement.
- [Modal billing](https://modal.com/docs/guide/billing): payment method required under standard terms. An event inference credit offer is not public-hosting entitlement.
- Render free-service and Cloudflare pricing docs: proxy403 in this environment, so current eligibility/card/billing/architecture limits could not be verified. No bypass or signup attempted.
- Managed runtime: no configured hosting credential or callable public HTTPS publishing capability discovered. Network readiness snapshot is currently unknown; individual official-document GETs succeeded as recorded in `phase4-source-manifest.json`.

**Decision: no public service provisioned.** Tested local container is the fallback; it does not provide a public HTTPS URL. External publication requires verified free/no-card terms, secure ingress and an audit of the actual URL. See `OWNER_ACTIONS.md`.
