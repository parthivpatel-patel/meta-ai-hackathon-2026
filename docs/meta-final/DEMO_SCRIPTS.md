# Demonstration and recording scripts

These scripts are prepared, not a claim that a final video was recorded. Use the reviewed exact candidate locally until deployment is separately approved. Current demonstrations must disclose **synthetic machine; deterministic or local-fixture proposals; zero genuine Meta calls**. Never relabel a fixture or recorded result as live inference.

## Three-minute technical walkthrough

1. **0:00–0:35:** Explain the coupled RPM/flow/head/load/thermal/vibration model, sensor versus process separation, component mappings and bounded deterministic playback. Demonstrate camera, selection and 2D fallback.
2. **0:35–1:10:** Capture observed telemetry; prepare its bounded numeric input. Show timestamps/reference hashes and explain why no private recipe, hidden fault label, trial witness or future measurement enters the request. Source labels stay visible.
3. **1:10–1:45:** Show structured competing proposals. Explain the exact prepared Baseten event target and private authorization/account/smoke gates. Current fixtures validate the integration contract, not actual model quality. Public HTTP routes cannot proxy a model call.
4. **1:45–2:20:** Confirm experiments and inspect counterfactual responses. Show independent verification contradicting an incorrect candidate or leaving ambiguity unresolved. State that the selector and verifier do not trust rationale or asserted certainty.
5. **2:20–2:45:** Export/replay, then show a malformed/tampered artifact being rejected without wiping the current investigation. Explain recorded source claims versus source authentication.
6. **2:45–3:00:** Summarize tests, synthetic/field limitations, genuine-model evidence still pending and the open development-window eligibility question. End on the reproducible report, not a chatbot screen.

## Recording checklist

- Record a reviewed SHA and note whether the source is local, live HTTPS or a replay. Hide private receipts, account screens, terminal environment and credentials.
- Capture machine/component controls, telemetry units/times, hypothesis source, experiment confirmation, verifier uncertainty and readable report. Include a narrow/fallback screenshot if relevant.
- Keep an unedited master recording and a short exported video outside ephemeral hosting; preserve JSON/HTML reports and checksums alongside it. Test playback on another browser/device.
- If a separately authorized real run later succeeds, replace only the relevant source/evidence segment with genuine reviewed results and required attribution. Label it recorded unless it is actually live. Do not claim better accuracy without the separately authorized matched evaluation.
