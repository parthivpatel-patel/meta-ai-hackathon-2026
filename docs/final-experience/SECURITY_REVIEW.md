# Separate critical review pass

This is a distinct same-agent review, not an external independent audit. Its scope is the tested candidate and bounded synthetic public interfaces.

Resolved findings:

- **High — replay identity and numeric representation:** real browser JSON changed integral float spelling, causing valid legacy recovery to fail. Recovery now normalizes only that numeric representation for comparison, with a raw boolean guard before coercion. The existing verifier/hash/report contracts are unchanged. Browser-normalized API, tampered-result/history and boolean-substitution tests cover the fix.
- **High — recovered state must not execute future work:** recovery independently reproduces only the existing submitted fixed-case state. A new temporary ID/version preserves prior trials and remaining budget; selection/execution still require explicit actions. Tampered, private/model-backed or arbitrary-source sessions are rejected. The browser checks returned content before attaching it.
- **High — continuity across hidden workspaces:** inspection selection/cursor are owned by their case workspace and included in the validated checkpoint; old asynchronous callbacks cannot navigate a different active case family. Reference geometry remains mounted/hidden across ordinary mode switches, without inventing unavailable operating data.
- **Medium — default boot overwrites a checkpoint:** a stored candidate blocks automatic replacement until explicit restoration/discard/save. Restoration is atomic for pump data and validates before attaching library data. A failed restore preserves current evidence.
- **Medium — browser storage denial misrepresents a successful action:** ID-memory storage errors are isolated from successful backend actions. They cannot produce a misleading retry of an already executed test. IndexedDB failures leave analysis/export available.
- **Medium — secret-bearing persistence:** only closed bounded machine/public-session snapshots are accepted; private provider records, credentials and private-owner sessions are excluded. Imported unverified telemetry is not autosaved. Private receipt/schema and credential-like input is rejected. Browser data remains untrusted and is not source authentication.

New `/api/v6/recover` is fixed-synthetic recovery, not a generic upload or inference endpoint. It uses the existing 1 MiB body limit, public rate/write limits, work gate, storage capacity and optimistic advance protocol. It ignores submitted identity as an authority and allocates a fresh session; it cannot overwrite another case. Recomputing prior synthetic history is an offline consistency check, not attestation that past operations actually occurred. No model provider is passed to reconstruction, and no arbitrary script/URL or physical actuation path was added.

The private one-request activation uses the existing controlled implementation only. No genuine call was attempted; financial attestations and protected credential readiness remain unmet. No usage dashboard was required. No request retry, evaluation or billing change occurred, and no private smoke success enabled public inference. Repeated tests use explicit offline fixtures, never genuine provider transport.

The final evidence includes automated configuration/API/security tests, non-root/read-only bounded local container checks, credential/dependency review and real browser flows. Automated Axe and emulated viewports are not full assistive-technology/physical-device certification. Credential pattern review is bounded, not proof that no secret could exist anywhere. Local Docker flags do not certify actual Render settings.

A narrow-table overflow found at 320px was corrected with bounded fixed table sizing. A lifecycle harness had treated the number of RAF paint samples as timer progress; it now retains actual timing observations and separately requires bounded two-tick cursor progress. Coalesced software-rendered frames are not fabricated into additional observations or hardware FPS. The exploratory failed timing output is retained.

Residual limits: latest checkpoint per family rather than an archive; browser eviction/clearing/private-mode limitations; ephemeral server sessions; no cross-device synchronization or source signature; reference legacy geometry rather than calibrated pump physics; only existing measured channels enter the verifier; software-rendered local performance is not hardware FPS; genuine model quality/access remains unverified. The pre-kickoff eligibility question remains OPEN. No unresolved critical/high finding was identified within the completed review scope; this is not a production-readiness guarantee.
