# Security and separate critical review

This is a distinct adversarial **same-agent review after implementation**, not an external independent audit or production/industrial certification. It covers the reviewed synthetic candidate, public/private boundaries, state transitions, imports/recovery, report consistency, cost gates, dependency/credential scans and actual local production-browser evidence.

## Preserved defenses and actual checks

- Public model inference remains disabled with budget zero. No genuine request, paid resource, financial attestation/billing change or public activation occurred. Current runtime reports no ready credential binding; owner-reported credits/key are not proof of credit-only spending.
- Existing strict public route allowlist, host validation, security headers, bounded bodies/imports/scenarios/experiments, request/work/store limits and non-root container launcher remain. The actual restricted public image passes the 32-check audit and refuses startup with a dummy credential. Developer/private APIs remain inaccessible publicly.
- Local test containers use read-only roots, tmpfs, one CPU/512 MiB and dropped capabilities. These flags and observed image identity are not independent certification of actual Render settings.
- Recovery imports are closed/versioned/bounded; credentials/private receipts/private-owner snapshots are excluded. Fixed public synthetic history is independently reproduced into a fresh legacy session ID; it is not authentication or proof of historical physical experiments. Future experiments still need explicit selection/execution.
- HTML escapes report content and validates reproduction before rendering. React renders rationales as text; private provider responses/credential files are not copied into public evidence. Known fixture keys remain dummy test values, not operational secrets.
- Dependency audits cover the current locked Python requirements and npm tree. Bounded credential scans cover changed text/public evidence, compiled frontend and owned local test logs; they never print matched values or inspect private secret files. A zero pattern count is not a universal guarantee about every external system or image pixel.
- Native IndexedDB tests cover round-trip, incompatible/corrupt/private data, quota/storage denial, failed/duplicate/stale restoration and preserved pending checkpoints. Actual browser tests exercise refresh, an actual Chromium restart, portable checkpoint import and owned-server session deletion/reconstruction.

## Honest boundary observations and residual risks

An exploratory rapid restart test exceeded the unchanged **ten public writes per minute** and correctly received 429. Its screenshot/transcript is retained separately. The checkpoint persisted. Final tests pace rapid restore/export/restart sequences around that window; no quota was raised and no uncertain experiment is automatically retried. Ordinary keep-alive traffic, production table deletion and paid upgrades are prohibited.

Browser checkpoints keep only the latest record per family. Storage can be denied/evicted/cleared, is not encrypted, is not cross-device and is not a durable server backup. Case/reset/operating controls deliberately create a new recording; export before replacing work. If the backend cannot load the initial simulation, use its visible retry after service/quota recovery; independent reproduction still needs the backend or offline CLI. No disconnected offline application guarantee is made.

Public demo sessions have no per-user account isolation and must not contain sensitive industrial data. The pedagogical simulator, normalized synthetic replicate tests and channel-only findings are not field calibration, a digital twin or safety certification. Emulated touch/viewports, automated Axe and software-rendered performance are not complete assistive-technology/physical-device/GPU validation. Finite heap samples do not prove absence of long-running leaks.

Actual Render Live identity/settings/rollback remain owner verification steps under the network restriction. Genuine model access/quality, financial entitlement, authenticated competition guidance, the OPEN pre-kickoff question, final video/access and submission remain external gates. Git history/timestamps are preserved; no organizer approval or disqualification is invented.
