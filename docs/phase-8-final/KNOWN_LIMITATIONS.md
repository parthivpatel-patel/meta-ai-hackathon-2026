# Known limitations and separate milestones

- Synthetic pedagogical pump and case evidence; no physical control, field validation, calibrated twin, industrial safety certification or unique physical-cause identification.
- Only motor temperature, vibration and discharge pressure enter the coupled verifier. Other displayed channels are simulation context. Library modalities and reference geometry are separate case evidence, not invented pump vision/audio reasoning.
- Fixed synthetic/fixture regression panels are known test cases, not new unseen industrial data or genuine-model evaluation. Selective precision must be read with coverage, abstention and false-negative denominators.
- Genuine Meta inference has never been verified by this phase. Financial charge protection and ready private access remain unresolved. The prior smoke allowance is unused and Phase 8 does not authorize execution. Public inference stays disabled.
- The retained library maps Telemetry/Evidence to its established evidence inspector and Replay/Reports to its report/offline-reproduction view. It preserves validated stages rather than introducing a second investigation engine or automatic replay execution.
- Browser recovery is the latest public checkpoint per family, not an archive, encrypted store, server backup or synchronization. Eviction/storage denial and ephemeral SQLite remain. Reproduction proves numerical consistency, not source authentication or actual historical execution. Private-owner/model-backed legacy sessions are excluded by design.
- Deliberate case/reset/manual-operating changes replace the active recording/capture. Tab changes, component inspection, resume and observed/counterfactual display changes preserve the investigation. Export before starting replacement work.
- Busy operations, absent instruments, imported recordings, manual actions and incomplete windows legitimately disable capture. Rate limits legitimately disable rapid computation until the window resets; do not weaken them or blindly retry uncertain tests.
- Browser tests use Chromium with emulated dimensions/touch and software SwiftShader; physical laptop/phone/GPU and full assistive-technology assessment remain owner checks. Automated zero Axe violations is not complete accessibility certification.
- Vite retains its existing >500 kB lazy Three.js chunk advisory; backend retains the existing Starlette/httpx deprecation. No large new dependency or unnecessary graphics effect was added.
- Local CPU/browser/heap/startup/serialization measurements are scoped samples, not Render cold-start latency, guaranteed FPS, production SLO or proof against all memory leaks.
- The owner-reported Render URL has not been independently verified for this candidate; no deployment/settings change occurs. Free idle spin-down, ephemeral storage and service limits remain. Availability through November 18 is a target, not a guarantee.
- Official authenticated eligibility/license/submission requirements and the OPEN foundation timing question require authoritative guidance. Preserve original history and evidence. No final video/upload, organizer contact or submission is claimed.

Software completion with these disclosed limits is distinct from genuine Meta activation, owner-approved live release and an eligible completed hackathon submission.
