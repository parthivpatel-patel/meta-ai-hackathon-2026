# Existing-engine integration

A capture requires at least sequence319 and an unmodified scenario. The adapter takes an80-sample baseline and40-sample incident window around the configured onset. Motor temperature, vibration and discharge pressure project into the existing three-channel `Measurement` contract. The legacy `minute` field is explicitly a **sample index** in this adapter; absolute timestamps and sample period remain in the machine evidence. Bearing temperature, flow and other readings remain useful inspection context, not additional independently verified channels.

The existing `observe`, blind candidate generator, structured hypothesis contracts, phase3 `select`, ordinal ranking and independent `verify` are reused. Recipe labels/latent truth do not enter candidate generation. No second frontend diagnosis engine or invented probability is used. The fixed four-test policy proposes an experiment; the operator reviews and confirms it. Arbitrary test design and physical control are not supported.

Reference acquisition and targeted counterfactual interventions use the same coupled simulator. Before/after fixed model states generate96 seeded synthetic primary/witness instrument replicates per channel. Normalization remains0.8°C/0.08mm/s/0.12bar around a healthy reference. Trials are marked `coupled-pump-1` rather than falsely claiming the legacy relaxation simulator. A versioned coupled-trial subclass carries that source tag; legacy Trial parsing remains closed to its original simulator. Old exports remain unchanged.

A counterfactual preview shows the actual resulting simulated instrument frame on the machine/inspector and the before/after plot. It does not overwrite observed recording history. Non-target responses or insufficient reductions can leave the old verifier inconclusive. Channel support must not be called unique physical bearing, alignment or cavitation identification.

New artifacts use `forge-industrial-report-1`, with capture component/time, recipe/version, machine/source, evidence window, observations, candidates, rankings, trials, events, decisions and limitations. JSON replay recomputes the model and verifier and compares the complete record, not just a supplied digest. The CLI is `uv run --frozen python -m forge.industrial.replay report.json --html report.html`; it is offline, creates a new HTML file exclusively and never calls a provider. Existing v1/v2/v3 formats and replay CLIs remain compatible.
